# chat_bot
Телеграм-бот для модерации групповых чатов: верифицирует новых участников и фильтрует спам-сообщения с помощью LLM.

---

## Возможности бота

### Верификация новых участников
Когда новый пользователь вступает в группу, бот немедленно отправляет ему сообщение с кнопкой **«Подтвердить человечность»**. Пользователь обязан нажать её в течение 3 минут (время настраивается). Если он этого не сделал — бот исключает его из группы. Уже верифицированные пользователи проходят проверку автоматически без повторного нажатия.

### Фильтрация спама
Каждое текстовое сообщение в группе проверяется в два этапа:

1. **Стоп-слова** — бот сверяет текст со списком запрещённых слов/фраз из конфига.
2. **LLM-анализ** — если стоп-слово найдено, сообщение отправляется на оценку языковой модели (OpenRouter Owl Alpha). Только если LLM подтверждает, что это спам, бот реагирует.

В зависимости от режима работы бот либо **удаляет сообщение и кикает пользователя**, либо **уведомляет администратора** со ссылкой на сообщение.

### Логирование
Все спам-сообщения записываются в файл `spam.log` с указанием ID пользователя и текста сообщения.

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone git@github.com:rkondratev/chat_bot.git
cd chat_bot
```

### 2. Создайте и активируйте виртуальное окружение

```bash
python -m venv .venv
```

Активация:
- **Linux / macOS:** `source .venv/bin/activate`
- **Windows:** `.venv\Scripts\activate`

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте файл `.env`

Скопируйте шаблон и заполните значения:

```bash
cp env.example .env
```

Откройте `.env` и укажите:

```env
BOT_TOKEN="токен от @BotFather"
LLM_API_KEY="API-ключ с https://openrouter.ai/openrouter/owl-alpha#api"
```

### 5. Настройте конфиг

Откройте `config.py` и при необходимости измените параметры (см. раздел ниже).

### 6. Запустите бота

```bash
python main.py
```

### 7. Добавьте бота в группу

Выдайте боту права администратора с возможностью **удалять сообщения** и **банить участников**.

## Настройка конфига (`config.py`)

### Режим работы (`ACTION_MODE`)

Бот поддерживает два режима. Активен тот, перед которым **нет** символа `#`.

**Режим `delete`** (по умолчанию) — удаляет спам-сообщение и кикает пользователя:

```python
ACTION_MODE="delete"
# ACTION_MODE = "notify_admin"
```

**Режим `notify_admin`** — оставляет сообщение, но уведомляет администратора:

```python
# ACTION_MODE="delete"
ACTION_MODE = "notify_admin"
```

---

### Никнейм администратора (`ADMIN_USERNAME`)

Используется только в режиме `notify_admin`. Укажите свой Telegram-никнейм **без символа @**:

```python
ADMIN_USERNAME="your_username"
```

---

### Список стоп-слов (`STOP_WORDS`)

Слова и фразы, при обнаружении которых сообщение отправляется на проверку LLM. Можно добавлять, удалять и редактировать:

```python
STOP_WORDS=[
    "казино", "заработок онлайн", "биткоин", "бесплатно",
    "промокод", "скидки 90%", "переходи по ссылке",
    "инвестиции", "крипта", "займы"
]
```

---

### Таймаут верификации (`VERIFICATION_TIMEOUT`)

Время в секундах, которое даётся новому участнику для нажатия кнопки верификации. По умолчанию — 180 секунд (3 минуты):

```python
VERIFICATION_TIMEOUT = 180
```

## Структура проекта

```
chat_bot/
├── main.py          # Точка входа, запуск бота
├── config.py        # Настройки: режим, стоп-слова, таймаут
├── handlers.py      # Логика верификации и фильтрации
├── keyboards.py     # Инлайн-клавиатура верификации
├── llm.py           # Запросы к LLM через OpenRouter
├── database.py      # SQLite: хранение статуса верификации
├── env.example      # Шаблон переменных окружения
├── .env             # Токены (не коммитить в репозиторий!)
├── bot_database.db  # БД (создаётся автоматически)
├── spam.log         # Лог спам-сообщений (создаётся автоматически)
└── requirements.txt
```
