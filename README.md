# chat_bot
чат-бот для верификации пользователей в разделах группы и фильтрации сообщений

# Модули проекта:
- [ ] Верификация новых участников;
- [ ] Фильтрация сообщений от верифицированных пользователей:
   - [ ] Cписок ключевых стоп-слов/фраз;
   - [ ] Системы запросов к LLM;
   - [ ] Наличие разных режимов работы у бота с возможностью переключения через конфигурационный файл
